Measured Bicycle Rim Weights

The bare-rim weight makers rarely publish — gathered from one workshop's build reports, searchable and sourced.

As the wheel weight guide argues, the advertised front-plus-rear total tells you little; the number worth knowing is the weight of the bare rim, and almost no brand prints it. This table collects rim-alone weights recorded over years of builds. Each figure is for a single bare rim and links to the post it came from. It is a curated, growing selection — in the source reports many rims are weighed only in a scale photo, so the list keeps expanding as those are read off and added.

How to read this: a measured tag means the source states an actual weighed figure for the bare rim; catalog means only a nominal weight was given. Individual rims vary — often ±5–15 g, sometimes more — so treat each number as that sample, not a guarantee. Click any column heading to sort; type to filter.
