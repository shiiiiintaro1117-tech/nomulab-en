買了 Topeak 的 DP Mount

March 27, 2026

我買了一個 Topeak（日本自行車配件品牌）的 DP Mount 產品。

↑就是這傢伙


DP Mount 是什麼
DP Mount 的意思是 Dropper Post Mount（坐管調整器座）。
夾緊部分的直徑是 27mm，


配套附帶 22mm 或 25mm 的墊片


卡住坐管調整器那較細的管子部分，
可以用來做為水壺架座、夾式後燈座、
或坐墊包（超大型的坐管包）的
坐管纏繞部分的座架。

如果是夾式的燈，
不用這種麻煩的座架
也能夠安裝，
不過對於水壺架和坐墊包來說，
耐荷重方面似乎有點令人擔憂。

除此之外，還有一個同樣用途的座架
叫做 EP Mount，
夾緊部分的直徑是 31.6mm，
通過墊片能夠縮小到
30.9mm 和 27.2mm
（名義上是電動自行車的坐管座架）。


↑這是每家每戶都有的
D 形車叉管柱的邊角料。



按照水壺架孔間的間距
鑽了孔。
M5 螺栓配合 4.8mm 的孔位，
所以螺栓不會鬆動掉落。


把螺栓穿過管子端部的孔洞很容易，



↑但這邊費了不少工夫。
還鑽了讓六角扳手通過的孔洞。


安裝到 DP Mount 上了。


螺紋長度剛好不會從本體突出來。


↑大概就是這樣


我有一個 Vaude（德國戶外裝備品牌）的
坐墊包，


纏繞在坐管上的固定帶
在踩踏時會微微碰到大腿內側，
這點讓我有點在意。
特別是在剛開始騎行的時候會比較明顯，
不過騎了一段時間以後
就沒那麼在意了。
就像口腔裡舌頭的位置，
當你意識到它時就會感到奇怪，
但很快就會忘記這種意識。

不過考慮到這個坐墊包在需要的時候
會被用於相當長時間的騎行，
我擔心騎行褲的布料
在那個地方會磨損，


所以我想在坐管的後面
增加一個虛擬的坐管，
因此買了 DP Mount。
不用附加 D 形車叉管柱的邊角料
似乎也能用於纏繞坐墊包固定帶的用途，
但我想避免讓帶子彎曲變形，
並且減少晃動，
所以才做了開頭的加工。

DP Mount 的夾緊直徑是 27mm，
坐管直徑是 27.2mm，
不過還是能夠安裝的。
如果對這個 0.2mm 的尺寸差很在意的話，
可以買 EP Mount，
從 31.6mm 縮小到 27.2mm，
但比起用墊片填充的固定方式，
我更討厭 0.2mm 的尺寸差，
所以選擇了 DP Mount。

對於鋼製車架，
我經常使用鈦坐管來避免固著現象，
實際上這台 Niner（美國自行車品牌）也是這樣，
但對於重量輕的碳纖維坐管來說，
用 EP Mount 縮小到 27.2mm
會更安全。
不過說到底，也不該用那麼輕的碳纖維坐管來運裝坐墊包。


↑大概就是這樣
包包的安裝角度也改變了。


單看固定帶的部分，
管柱似乎可以短一些，
不過為了支撐住包包的前端部分，
需要這個長度。

用這個配置騎過一次以後，
完全感受不到
安裝了坐墊包的感覺。
至於今後是否真的這樣運用
還沒決定。
