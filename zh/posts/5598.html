用 Zonda DB 花鼓和 Racing 3 DB 輪圈組裝前輪

February 26, 2021

今天也是輪組（以下略）。

我從客人那裡接收了 Racing 3 DB 的前輪。
旋轉盤座是中鎖式，
但包括 Shimano 在內大多數廠商的鎖環都是「外螺紋」，
也就是說是中空螺栓的形式。
無論使用外鎖式還是內鎖式工具，這都不會改變。

但這在 Fulcrum 的碟煞完組輪組中
鎖環一側是「內螺紋」，也就是螺帽的形式，
使用的工具僅限於外鎖式。
因為是與花鼓本體一起設計的結構，
除了附屬的鎖環之外無法使用其他的。


結果花鼓本體外螺紋側的螺牙被磨圓了。
旋轉盤無法固定，永遠在旋轉，
所以整個輪組都沒辦法用了。


↑磨屑還飛進了防塵蓋部分。

關於這個輪組，不知道是現在的車主造成的，
還是從別人那裡便宜買來的已經壞了的。
作為讓它重新能用的提案，
我向客人提議用 Shimano RS770 花鼓的 28H
跳過右側一個孔穴、當作 21H 花鼓來重新組裝。
用 28H 花鼓配 21H 輪圈相反的例子——
用 21H 花鼓勉強配 28H 輪圈的情況
（→這裡）和（→這裡）也有過，
大概也是這樣的做法。
和輪圈孔不同，多出來的花鼓法蘭孔
不需要堵住，大概就是這個差別吧。

順便說一下，我只在前輪才會提這個建議。
一側 7H 是折頸輻條就已經夠嚇人的了，
後輪的話因為 7H 放射線組組一側有旋轉盤座
還是避開比較安全。
RS770 花鼓因為花鼓本體的設計繼承了 CX75 花鼓的傳統，
法蘭孔是有狹槽的。如果要做左右反向異徑組合的話
7H 側也有可能用 Sapim 的 CX 之類的，
但 CX 黑色沒有穩定供應，
銀色的話立即能取得的長度也受到限制，這是問題。

在這個時點話題就停下來了……


前些日子客人說「反過來輪圈那邊也壞了，
拿到了一個 Zonda DB，請幫我拼湊一個吧」。
天啊啊啊啊啊啊啊啊

太勉強我了！
如果他一開始就問我「能用 Zonda DB 的花鼓組嗎」的話

↑我會直接拒絕說「Fulcrum 的 2:1 和 Campagnolo 的 G3
相位不符，沒辦法」。

不過既然已經買了也沒辦法，
雖然有點沉沒成本謬誤的感覺，但都走到這步了不出結果
也太浪費了，所以還是試試看。

Zonda DB 和 Racing 3 DB 的花鼓和輪圈
其實差異還挺大的。
嗯，Campagnolo 和 Fulcrum 本來就是
完全無關的不同廠商啊（表面上）。


Racing 3 DB 的花鼓。輪圈煞車型號上也有的
像冰淇淋被湯匙挖出來的樣子的減重設計。
要不是黑色花鼓的話汙垢會很明顯


Zonda DB 的花鼓。
這個恰好是 6 螺絲孔規格，
但也存在中鎖規格。
客人說旋轉有點咯咯的，
但其實只是軸承間隙調整得太緊了。



Racing 3 DB 的花鼓在輻條頸部下方的一定範圍內
要求輻條呈直線。



而 Zonda DB 的輻條頭
是貼著法蘭邊緣一樣的結構，
所以輵條頸部下方的角度擺幅有點餘量。

這是很關鍵的。
這次的情況恰好比較順利，
看起來可以用 Zonda DB 花鼓配 Racing 3 DB 輪圈。
反過來的話怎麼辦呢？
既然已經買了材料，只能組啊，
所以結果應該也是會組下去。


小心翼翼地拆開了 Zonda DB。

Racing 3 DB 的輵條變粗部分比較粗。
Zonda DB 是左右同徑組合。
初代 Zonda DB 似乎是左右逆異徑組合，
但從型錄上首次出現的 2017 年型號
（Zonda 和 Bora One 推出 DB 規格時）開始
左右都是 2.0-1.6-2.0mm。

關於 Racing 3 DB，Fulcrum 的型錄中
對左右逆異徑組合完全沒有提及
（我也查了非日文的型錄）。
Racing Zero DB 的鋁輵條從橫向看左右寬度相同，
但少輵條側前後輪的厚度都比較厚，
做了很手工藝的設計，
但對此也完全沒有提及。

Racing 3 DB 的少輵條側是 2.0-1.8-2.0mm，
和 Comp 的規格相同。
Racing 3 DB 的多輵條側和 Zonda DB 的左右都是
2.0-1.6-2.0mm，
但這比 Revolution 和 Laser 的變粗部分 1.5mm
稍微粗一點，應該是圓斷面輵條
為了不產生扭轉而攻略的極限。

無論輵條材質如何，Fulcrum 把碟煞輪組
做成左右異數組合的反向器使用左右逆異徑組合，
在理論上是更先進的。
型錄上也沒有標記，所以 Racing 3 DB 的所有者
有可能一輩子都注意不到左右輵條番手不同，
竟然還這麼費力地做這樣手工的設計，真是了不起。

先前說的完組撓片，相比通用撓片
螺牙開始得早（牙周囊淺），
螺牙部分相比通用撓片略偏內周。
完組撓片和通用輵條的組合中，
輵條端不會抵到尼龍。
但能確保普通撓片同等程度的
螺牙咬合量，所以組輪組沒問題。

各方面都不同的 Racing 3 DB 和 Zonda DB，

Racing 3 DB 是 2WAY-FIT 的 C19 輪圈，
