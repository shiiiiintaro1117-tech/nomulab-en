Fulcrum Tire Levers Have Arrived

September 03, 2016

Seems like someone's been keeping tabs on this place.

The other day I sent a message to a certain someone saying "If you've got a Fulcrum tire lever, send it my way," and would you believe it actually arrived.
To make sure it doesn't cause any trouble, I've pixelated it so there's absolutely no way to tell where it came from.


The address label says "Dark Bicycle Workshop" instead of our ATHENA shop name,
but that can't be helped.
That's what I call myself when I place orders with this wholesaler.


Here's the "Fulcrum tire lever," and I need to explain something about it.




When I place orders with this wholesaler, I've been drawing
puffy speech bubbles in the Campagnolo section
and a long, stubby dog in the Fulcrum section,
then writing the brand name inside.

This long, stubby dog has become known in certain circles as the
"Fulcrum Dog" (the character ken meaning dog, not inu),
and apparently someone really took a liking to it, because


the other day, an enlarged print of the image on A4 copy paper
was mixed in with my delivered order.
Apparently what's funny about it is that the number of back legs is wrong.

So yes, it's true that a tire lever with the Fulcrum Dog image stuck on it
was sent to me, but


the actual genuine article was also included in the package.
While these tire levers aren't exactly nonexistent on the market,
the one that comes with Fulcrum wheels is
a "Campagnolo black tire lever without the Campagnolo logo,"
so it seems to be something of a rare item.


Between Campagnolo and Fulcrum, even parts that look identical are given different part numbers,
and you're not supposed to mix them.
However, tools basically share the same part number. For example,
the spoke wrench is T-02 for both brands.
For tire levers too, they're the same part number WH-109HYC, so
if you order this number as a Fulcrum spare part,
a logo-less black lever should arrive.

So the reason the Campagnolo logo disappeared from the tire lever
appears to be so it could be shared with Fulcrum (officially they're supposed to be separate companies)...


This red lever is from December 2014, so it's relatively recent.
What on earth is going on here...?

I was doing some research on Fulcrum tire levers, but
once this post goes up,
this article itself will become an obstacle to that research (it'll show up in search results).
So I made sure to finish all my research before posting this.
