I Can't Build the Rear Wheel

November 18, 2013

DT spokes were shipped from the distributor on Friday,
but they still haven't arrived.
This is a problem with the shipping company, not the distributor.
（※Not Sagawa or Yamato!）

Since the distributor is closed on weekends, they shipped on Friday,
but it didn't arrive today, Monday either,
which means it would have been faster if I'd gone to pick them up myself in the end.
Forget it—I'll go pick up the comp wheels tomorrow morning.

I'll have a talk with the shipping company about the repeated late deliveries without notice cards.

So today too, wheel building（abbreviated）is just front wheels.

Built the front wheel for Nomu Lab Wheel #2.


The Tni Evo Hub rear 24H hubs are sold out,
but the front 20H hubs are still available so I can build the front wheel.
This customer's rear wheel is #3 20H, so with matching Tni hubs front and rear, I built it.

The replacement hubs are supposed to arrive on the 21st in the evening.


Built the front wheel for Nomu Lab Wheel #5.


It's 32H because it's the matching rear wheel that's 32H.
That rear wheel is a PowerTap, though,
and I was asked to rebuild it.
Sorry, I didn't quite catch that.


Built the front wheel for ENVE 1-45TU.


Radial laced with Nipo spokes.
Since I've been given full discretion in selecting spokes for this rear wheel,
I could go with full CX-RAY instead of semi-comp,
but I didn't have time to build it today anyway, so I'll think about it a bit more.


Built the front wheel for Nomu Lab Wheel #1.


Once the spokes come in, I'll build Nomu Lab Wheel #1 with an Altegra complete rear hub,
but I built the matching front wheel first.
