I Stocked Up on Various Hubs

June 20, 2023

Recently I got some stock of the disc road hub that Tni (a hub manufacturer) released


a hub called DURO.
I'm assuming the pronunciation is "Duro."
Going forward I'll call it the Duro hub.
The price is lower compared to the Revo Disc hub,
but the anodized color and finish of the Revo Disc hub has more of a premium feel.
The Duro has a wider flange width than the Revo Disc,
for example on the rear hub the Revo Disc's nominal spec is 48.5mm while
the Duro is 57.4mm! Or I'd like to say that, but
since the OEM source is different between the hubs, the
flange width definition in the spec sheets submitted is different—
Revo Disc measures flange inner-to-inner while Duro measures outer-to-outer,
so the numbers are just bigger.
By the way, with Novatech-brand hubs like the Evo Disc II hub or Evo Lite hub,
the flange width is measured center-to-center.

Comparing the retail price including tax and nominal weight between Revo Disc and Duro respectively:
Front hub is 8,140 yen / 132g and 5,500 yen / 135g,
rear hub is 13,200 yen / 245g and 9,900 yen / 284g,
so the cost performance is good and the front hub weight is so close that
if you deliberately picked heavier Revo Disc and lighter Duro
you could even see an actual weight reversal, but
the Duro hub has some inconvenient aspects.
The Revo Disc hub spoke hole configuration is only 24H front and rear,
but with the Duro hub the front is 24H only and
the rear is 28H only. What's that about?
Well, it's not like there's no use for it, so
I actually ordered some stock anyway.


Next, separate matter.
The Evo Lite hub that we stock only as a rim brake rear hub for
SRAM XDR or Campagnolo freebody, but the
backorders for wheels from SRAM and Campagnolo have
exceeded our hub inventory levels, so

just the other day I had an opportunity to get the Novatech 482SL hub
that's the original behind the Evo Lite hub
(it comes with a Shimano freebody though), so
I stocked it. I'll use all of these hubs only for SRAM XDR or
Campagnolo applications, and
the Shimano freebody that comes with the hub
I'll use only as spare parts for Shimano freebody.
