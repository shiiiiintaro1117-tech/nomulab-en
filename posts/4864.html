Built a front wheel with AL22W disk rim

September 29, 2019

Another wheel day (and so on).

I built a front wheel using Tni's AL22W disk offset rim.


Tni REVO (I'll call it REVO from now on) disk hub, 24H
All CX-RAY 64-spoke reverse Italian lacing.
I'll do the nippling later.


As for the REVO disk hub, as I've mentioned before,
both front and rear are 24H only 12mm thru-axle hubs.


Green aluminum nipples.
That's fine, but regarding this rim's offset design—
the AL22W rim comes in two versions: one for rim brakes and one for disk brakes.
The disk brake version has no brake zone, as you can see in the image above.
Both rim types come in non-offset and offset versions,
but following what DT does with the RR411 rim,
I'm thinking the non-offset version isn't really necessary for disk brakes.

I went with full CX-RAY lacing instead of half-comp
because the customer's use is more toward disc road than cyclocross,
and also because it's an offset rim.
If it were a non-offset rim, I'd probably have used half-comp lacing instead.

Both Tni's hubs and rims are relatively affordable
while maintaining good precision materials, so
I might make this wheel built with the REVO disk hub and AL22W disk rim
into Nomu Lab Wheel No. 8.
