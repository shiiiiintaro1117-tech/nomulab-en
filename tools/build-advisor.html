Wheel Build Advisor

Tell it what you're building and it returns a recommended lacing pattern, spoke gauges and spoke length — the way one workshop would call it, with the reasoning linked.

The build

Hub & rim measurements — optional, for spoke length

Leave blank if you only want the build recommendation. "Right" = drive (freehub) side. Flange diameter is to the spoke-hole centres; centre-to-flange is the distance from the wheel centreline to each flange.

Read me: the recommendations encode the rules the Nomu Lab guides set out (each linked below the advice); they are a starting point, not a substitute for checking against your actual hub and rim. Spoke length uses the standard geometric formula, rounded to 0.5 mm (the workshop cuts in 0.5 mm steps); for crossed wheels the inpoke/outpoke difference is negligible. Always double-check a length before cutting.
